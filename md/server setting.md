# 🖥️ AI Development Server Setup

 Home AI Development Server for Deep Learning Research

## Overview

This document describes the development environment for my AI research and master's thesis.

The goal is to develop and train deep learning models remotely using my desktop GPU (RTX 3060) while coding on a lightweight laptop from anywhere.

---

## Development Environment

### Laptop

- Windows 11
- VSCode
- Remote SSH
- Tailscale
- WSL (Development)

### Desktop

- Windows 11
- NVIDIA RTX3060
- CUDA 12.1
- cuDNN
- Anaconda
- Python 3.10
- PyTorch 2.5.1 + cu121
- OpenSSH Server
- Tailscale
